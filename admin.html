Security Contract

Production safeguards

✓ Current admin must hold a valid Beta Admin Firebase session.
✓ Worker verifies the signed Firebase ID token and the admin allowlist.
✓ Production service-account credentials exist only as encrypted Worker secrets.
✓ User clients can read only their own admin-grant records and cannot create, update, list, or delete them.
✓ Trial reissues never delete or rewrite the original device-bound trial record.
✓ Every privileged action—including password assistance—requires a reason and writes an immutable audit record.
